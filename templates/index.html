09 · Reference
Log Discipline
▼
Standing rules for every log entry. No checkboxes — these are always in effect.
TimeEvery entry gets a timestamp. Use the Now button or attach GPS — it includes a timestamp. Never back-date.
Facts onlyLog what happened, not what you think happened. Use NOTE for unverified observations. Promote when facts are clear.
ConfidenceState it. Choose one: confirmed / likely / possible / unconfirmed / stale / inferred.
+GPSAttach when position matters. Never estimate coordinates — if no fix, note the absence and log a description instead.
Close loopsEvery ALERT and ACTION must be closed or explicitly superseded. An unclosed entry is an open task.
Chat ≠ LogChat is for conversation. Log is for record. Keep them separate. If it happened and it matters, it goes in the log.
MissionsTag entries to a mission / folder for grouping. One mission per activation as a minimum. Rename, never delete if entries exist.
10 · Reference
Category Reference
▼
When in doubt, use NOTE and promote later. Reserve ALERT and ACTION for things that need a response now.
NOTE
Unverified observation. Not yet classified. Review and promote when facts are confirmed.
SITREP
Full status at a point in time. Network, assets, issues, intent, and next update time.
PLAN
Pre-move or pre-watch order. Objective, route, comms plan, risk, and reporting triggers.
ALERT
Actionable problem. Power, comms outage, weather, or safety. Needs a response now. Must be closed.
ACTION
Assigned task with owner and status. Must be closed or superseded when complete.
COMMS
Radio check, ping, message path, relay test, or failed contact. Log results, not the discussion around it.
CONTACT
New station identified. First heard, path, signal quality, and follow-up action.
POSITION
Own station, mobile node, RPTR, or remote asset location. GPS when available; state confidence if not.
INTEL
Observed pattern, RC find, signal, movement, or infrastructure. Tag and assess reliability.
WEATHER
Conditions affecting operations. Temperature, wind, precipitation, visibility. Note impact on RF.
