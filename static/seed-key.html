Usage: seed-key.html#NAME=VALUE — e.g. #cartoApiKey=cb1_… (names per app are in the project docs). The part after # never leaves the browser: fragments are not sent to the server and no file stores it. The fragment is dropped from the address bar after saving. Send an empty value (#NAME=) to clear a key. Nothing here is bundled with the app — this page is a convenience for entering your own key on a device where typing is awkward.
