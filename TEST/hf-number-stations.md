# HF / Number Stations

## Before You Listen

- [ ] Check **priyom.org** — live crowd-sourced schedules, current frequencies, recent logs
- [ ] Tune in 2 min early — most stations transmit on the hour or half-hour
- [ ] Mode: AM or USB — number stations rarely use LSB
- [ ] Patience: some transmit only 1–2× per day, for 5–10 minutes only

## UVB-76 "The Buzzer"

- [ ] Tune to **4.625 MHz** — mode USB or AM
- [ ] Listen for continuous mechanical buzzing tone (runs 24/7)
- [ ] Best heard: evening + night (40m propagation from Russia improves at dusk)
- [ ] Occasional voice interruptions — callout of station ID + numbers (rare, military exercise)
- [ ] Most reliable number station in Europe — start here to confirm HF + antenna working

## E11 "Oblique"

- [ ] English female voice, 5-figure number groups
- [ ] Frequencies vary — check priyom.org for current (commonly 6.959 / 7.887 / 10.195 MHz)
- [ ] Mode: USB
- [ ] Active station, regularly heard in Central/SE Europe
- [ ] Transmits at scheduled times — fixed days + hours

## S06s — Slavic Stations

- [ ] Male or female voice, counting / number groups in Slavic language
- [ ] Frequencies: 5–12 MHz range, irregular schedule
- [ ] Mode: USB or AM
- [ ] Closest geographic origin — likely stronger here than English/Spanish stations when active

## HM01 — North Korean

- [ ] Female voice, Korean, 3-figure groups
- [ ] Many frequencies across HF — check priyom.org for current schedule
- [ ] Audible in Europe on 20m / 17m during daytime with good propagation
- [ ] Mode: AM
- [ ] Transmits at fixed times, multiple times daily

## V13 / M12 — Russian Morse & Voice

- [ ] Various frequencies 4–14 MHz, evening and night
- [ ] Less predictable schedule — monitor 40m + lower bands after dark
- [ ] Mode: CW (morse) or USB voice
